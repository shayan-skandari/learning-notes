# Terminal Notes

## What is Terminal?

 A terminal is a place where you give commands to the computer by typing instead of clicking.✍️

 ## Commands I learned

 - `cd` : - `cd` : moves me into another folder
 - `ls` : - `ls` : shows files and folders in the current folder
 - `mkdir` : makes a new folder
 - `cat` : shows the content of a file in the terminal

 ## Paths
- **Absolute path** : starts from the root, like `C:\`
- **Relative path** : starts from the current folder, like `Desktop\git-practice`
- `..` : means the parent folder
