# Git Notes

## What is Git?

Git is a tool that keeps the history of changes in my project.💻

## Commands I learned

- `git status` : shows which files changed.
- `git add` :  prepares a file for commit.
- `git commit` : saves the changes in the history.
- `git log` :  shows the list of commits.

## Working with GitHub

- **Pull Request** : a request to review my changes and merge them into main
- `git push` : sends my commits from my laptop to GitHub
- `git pull` : brings changes from GitHub to my laptop
