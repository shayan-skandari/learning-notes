# Errors Notes

## How to read a Traceback

- Read it from bottom to top
- The last line shows the error type and the message

## Before fixing an error

- Check who gave the error (Windows, Git or Python)
- Check if a command really exists with `-h`

## How to ask a good question

1. What I wanted to do
2. What I did
3. What happened, with the full error
4. What I tried
